# 三层归因框架（感知/规划/控制）——映射表与预注册实验

> 定稿 2026-07-27（Rick 批准 7/26 草稿）。用途：①指挥 W2/W3 归因实验；②作为可复用标注量规，后续评 OpenVLA-OFT / π0 直接套用。英文版随 W7 report 定稿再出。
> 方法论：所有干预实验**先预注册预测再开跑**（防马后炮偏差，先例见 `failure_videos/ANNOTATION_zh.md` 赛前预测节）。

## 三层定义

| 层 | 回答的问题 | 典型修法 |
|---|---|---|
| 感知 | 看对了吗（语言 grounding、物体识别、几何/深度理解） | 视觉编码器、相机视角、指令表述 |
| 规划 | 认知正确的前提下，选对下一步了吗（子目标、失败恢复、状态覆盖） | 数据分布补洞（恢复演示）、chunk 设计 |
| 控制 | 决定正确的前提下，做得到吗（精度、力度、时序） | 动作头容量、数据侧精细操作演示、控制频率 |

⚠️ SmolVLA 是端到端模型，**没有显式的三层模块边界**——三层是功能透镜，不是代码模块。定层结论的含义是「干预哪个环节能救活」，指导修复方向（数据/训练/接口），不是指认某段网络。

## 预注册实验（R → F → T）

### Exp R：重放保真（进行中，2026-07-27 发射）

同命令、同 seed(1000)、同 checkpoint 重跑 30k 官方评测 100 集（输出 `smolvla_spatial_b64_30k_ckpt030000_n1_replay20260727`）。**已知环境差异**：原跑（7/20）在旧 conda venv（torch 2.11.0+cu126），本跑在 uv venv（同 torch 版本、cu130 运行库）——运行库更换 + GPU 非确定性算子都可能让闭环轨迹混沌发散。

判据分四级：L1 总成功率（82 ± 二项噪声）→ L2 逐任务分布 → L3 逐集成败网格全同 → L4 逐帧。
**Claude 预期**：L1/L2 守住，L3 大概率不全同（若全同，「逐集确定性复现」升级为 harness 卖点声明）。
⚠️ 判读纪律：R 中 ep3 是否复现死机**不裁决**「单次事故 vs 系统模式」——若栈是确定性的，复现是构造结果；若不复现，是数值发散不是行为证据。裁决交给 F。

### Exp F：ep3 事故性检验（fluke test）

task5 ep3 的初始布局（LIBERO init state 按集序号固定）× 10 个新噪声 seed。唯一变量是策略的 flow-matching 采样噪声。

- **Rick 预注册（7/27）**：死机不复现或 ≤1/10——「单次傻了」，纯事故。
- **Claude 预注册（7/27）**：1–3/10——低频但真实的模式（那个状态出自策略自身的行为分布，不是零概率角落）。
- 裁决线：0–1/10 = Rick 对；2–3/10 = Claude 对；≥4/10 = 双方皆错，30k 标注里 H4=1/8 是 seed 运气掩盖的主要模式。

### Exp T：中间态接管（内部代号 teleport）

3 个注入状态 × 各 10 噪声 seed = 30 局：ep6 抓取后（神谕）、ep8 抓取后（神谕）、ep3 自身抓取后（事发状态）。

- **Claude 预注册（7/24）**：神谕状态 ≥8/10 走完；ep3 自状态死机复现为主。
- 判读矩阵：神谕高 ∧ ep3 低 → 锅在状态，规划层分布覆盖坐实；神谕高 ∧ ep3 高 → ep3 属采样事故（与 F 互证）；神谕低 → 放置后半段能力本身缺失，问题更深。
- 工程依赖：rollout 探针脚本（指定 init state / 逐步 dump MuJoCo 状态 / 状态注入后接管），W3 工具化产物，同时服务几何扫描与落点分布。
