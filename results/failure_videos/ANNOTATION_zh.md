## 统计与结论（2026-07-24 定稿：Rick 标注并拍板分类，悬案 ep2/3/5 由 Claude 抽帧核验）

| | H1 指错碗 | H2 抓取 | H3 放置 | H4 超时 |
|---|---|---|---|---|
| task5（8 失败） | 0 | **5**（ep0,2,4,5,7） | 2（ep1,9） | 1（ep3） |
| task8（4 失败） | 0 | 1（ep2） | **3**（ep4,5,9） | 0 |

1. **H1 = 0/12**：所有失败都走向了正确的碗，语言 grounding 不是瓶颈，「二选一随机混淆」假说出局。这是全表最锋利的结论。
2. **task5 主因 H2（5/8）**，赛前 Rick 与 Claude 均预测命中；但 5 例中 2 例是赛前未预料的子模式**「双碗同抓」**——不是抓空，是不会「只抓上面那只」（下爪过深，把 bowl+ramekin 当整体夹走）。
3. **task8 主因 H3（3/4）**：碗紧贴盘子、搬运极短，失败集中在放置精度。两任务主导模式不同，report 中分开表述。
4. **成功谓词比直觉严**：`On` 要求直接接触 + 碗心盘心 xy<3cm。ep5（task5）整摞放进盘子判负、task8 ep5/9 搁在盘内缘判负，均属「行为接近成功、按定义判负」。跨 benchmark 比成功率必须先对齐评分谓词——放宽谓词本作 task5 2→3、task8 6→8。
5. **失败后恢复行为丢 grounding**（task5 ep1/ep9 放置失败后去抓旁边的碗、ep7 重试总对着 ramekin）：训练数据无失败恢复演示，失败态即 OOD。
6. 机制线索：正式评测口径是 **`n_action_steps=1`**（每步重推理；chunk_size=50 只执行首步，见 STATUS.md 2026-07-19 决策）——**失败不是开环盲执行造成的**。策略每步都拿到新观测，仍持续走向双碗同抓/盘缘放置，失败后还转向错误对象。修正能力的缺口在策略本身（训练数据无失败恢复演示，错误态即 OOD），闭环频率已到顶，不存在低成本推理侧旋钮。
